# Opdrag Tutors

### Frontend Project — HTML, CSS, JavaScript

---

## 📘 Project Overview

**Opdrag Tutors** is a web-based platform designed to simplify the process of finding and booking university-level tutorials. The platform enables students to browse available tutorials by module or university, upload their assignments, and automatically get matched with a suitable tutor.  

The project emphasizes responsive web design, clean user interfaces, and smooth interactivity powered by **JavaScript**. It provides a seamless experience for both students and tutors, improving accessibility and efficiency in academic support.

---

## 🧩 Key Features

- **Tutorial Search** – Browse available tutorials by university, module, or tutor specialization.  
- **Smart Matching System** – Automatically connects students with qualified tutors based on uploaded assignments or selected subjects.  
- **Assignment Uploads** – Students can upload documents directly to the system for tutor review.  
- **Booking Management** – Simple and intuitive interface for scheduling or modifying tutorial sessions.  
- **Responsive Design** – Built with HTML5 and CSS3 to ensure optimal experience across devices.
